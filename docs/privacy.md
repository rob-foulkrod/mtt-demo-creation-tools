# Privacy

MTT Demo Creation Tools is an open-source collection of instructions and approved fictional-data
lists. The distributed packages do not include a hosted service, remote MCP connector, telemetry
client, or credentials managed by this project.

The skills run within the Copilot experience where you install them. That host and any tools you
authorize may process prompts, files, generated artifacts, and activity under their own terms,
privacy policies, and your organization's controls. GitHub hosts the source and release downloads
under GitHub's applicable policies.

The skills require public-safe fictional demo content. Do not provide confidential customer data,
real employee records, credentials, private tenant details, or other sensitive information. Review
generated output before sharing it, and approve any write to a shared or public destination.

Report project issues through the public GitHub repository without including sensitive information:
https://github.com/rob-foulkrod/mtt-demo-creation-tools/issues

Package use is subject to the repository's MIT license. This notice describes this project's
packages; it does not replace Microsoft, GitHub, or your organization's privacy policies.
